# Visual Stimulus Analysis Using Python

## Project Overview

This is an independent computational visual neuroscience project focused on generating and quantitatively analyzing controlled visual stimuli using Python.

The project explores how stimulus properties such as contrast, spatial frequency, and orientation can be manipulated and analyzed.

## Objectives

- Generate sinusoidal grating visual stimuli using Python.
- Analyze pixel intensity, minimum and maximum intensity, and mean luminance.
- Calculate and visualize stimulus contrast.
- Examine the distribution of pixel intensities using histograms.
- Systematically manipulate stimulus parameters, including contrast, spatial frequency, and orientation.
- Explore basic computational models of visual neuronal responses.

## Tools and Libraries

- Python
- Google Colab
- NumPy
- Matplotlib

Currently in progress.
